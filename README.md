One sentence that explains the modern internet to a time traveler who has just stepped out of the year 1800, built only from what a person from 1800 already knows: a post office, a letter, a house, a horse. `main.py` (pure Python 3, no dependencies) writes that single sentence to the output path and checks it against the gate first: 1–200 characters, one sentence, UTF-8.

> Picture a post office with no walls, where a letter from any house reaches any house in the world before a horse takes a step, and any man may read what any other man has written.

## Run it

```sh
OUTPUT_PATH=/tmp/traveler-out/entry.txt python3 main.py
```

Without `OUTPUT_PATH` the sentence is written to `/output/entry.txt`.
